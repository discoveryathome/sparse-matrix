# Featured-project candidate: reduce sparse-factor fill-in

## Public-facing explanation

Many scientific computations solve systems whose matrices contain mostly zeros. Factoring those matrices can create new nonzero entries. Changing the elimination order can reduce that extra storage without changing the original problem. Contributors search for better orders and submit a permutation that anyone can check.

## Why this is a candidate

The score is exact and inexpensive to verify. Small contributions accumulate into inherited per-instance frontiers. Search methods are open-ended. Broader qualification found gains across structural and synthetic patterns; new power-network inputs supplied a second empirical application family. Most importantly, a fresh donor rehearsal improved all six selected tasks after inheriting every earlier verified result. This establishes another step of marginal progress, rather than repeatedly beating weak starts.

## Claims to use

- Verified reductions in symbolic Cholesky factor storage on specific benchmark instances.
- Transparent inputs, inherited frontiers and reproducible contribution certificates.
- Open research into which methods generalize and when search overhead is worthwhile.

## Claims not yet supported

General numerical speedup, guaranteed whole-process memory savings, production-workload representativeness, new global/literature records, or independent human scientific signoff. The corpus still has only two historical empirical families and sixteen synthetic inputs. Six selected donor tasks do not estimate a random contributor's success rate.

## Suggested feature scope

Feature the symbolic-ordering challenge first, after launch checks pass. Treat end-to-end solver performance as a separate research track. Keep intake open and allow external experts to review the scoring and baseline choices. Do not make application performance promises from the current timing data.

Prepared artifacts: README, contributor commands, 28-instance current frontier, independent checker, negative tests, candidate PR validation, separate standings, issue template, discussion draft, and visual evidence. This brief is a candidate package, not an assertion that the site or repository has been published.
