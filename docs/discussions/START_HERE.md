# Welcome: improve an inherited sparse elimination order

Contributions and expert review are open. Start with README.md, pick a matrix from the current frontier and run a bounded search. Submit a permutation, full trace and exact verifier output. Different search methods are welcome.

An improvement is measured against the best verified order already inherited by that instance. Storage and arithmetic-proxy scores are exact; runtime claims need separate evidence. Older frontier versions remain reproducible.

Please use the research issue template for baseline/benchmark questions or materially different search proposals. Scientific and reproducibility reviews are welcome contributions in their own right.

Draft for pinning after publication; not posted automatically.
